01/About

Built quietly. Now showing the work.

Years of shipping, one repository at a time — and now, the story behind the code.

For years, I built quietly. Late nights, one repository after another — tools, bots, apps, extensions — most of it published in the open on GitHub, long before anyone was watching. 128 repositories and 14 programming languages later, this is not a plan I’m showing off. It’s the work.

I work across the whole stack. TypeScript and React on the front end, Python and Node.js on the back end, Flutter and Kotlin on Android — and deep inside the MIT App Inventor ecosystem, where I build extensions (.aix) and the Aixfy toolchain that helps other developers build them too.

My style is simple: ship early, ship often. PyRunner — my Android app for running Python projects on the phone — went from an idea to 11 releases in a single day. I don’t just learn tools. I build with them, break them, fix them, and ship again. Now it’s time to show the work to the world.
